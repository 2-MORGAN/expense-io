Les consignes pour les agents IA de ce dépôt sont dans [`CLAUDE.md`](CLAUDE.md) : le lire avant toute modification. Il renvoie vers la carte du code ([`CODEMAP.md`](CODEMAP.md), à lire avant d'explorer), la recette d'une fonctionnalité ([`.claude/skills/nouvelle-fonctionnalite/SKILL.md`](.claude/skills/nouvelle-fonctionnalite/SKILL.md)) et le détail à ouvrir seulement si la tâche le demande ([`docs/agents/`](docs/agents/)).

Toute modification du code met aussi à jour la doc des développeurs, [`docs/index.html`](docs/index.html), et ses schémas Mermaid de [`docs/architecture/`](docs/architecture/README.md), dans la même PR. Ce qu'il faut mettre à jour selon le changement : [`docs/agents/documentation.md`](docs/agents/documentation.md). `npm run generate:architecture` recopie les schémas dans la page et régénère `CODEMAP.md` ; `npm run check` échoue si l'une ou l'autre a dérivé.
